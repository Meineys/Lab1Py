## Задания

### Задание 1 — Перекидыватель слов (1 балл)

**Файл:** `ex1.py`

Форма содержит два поля ввода и кнопку со стрелкой между ними. При нажатии кнопки строка из первого поля переносится во второе, а стрелка меняет направление. Повторное нажатие возвращает строку обратно и восстанавливает исходное направление стрелки.

**Используемые виджеты:** `QLineEdit`, `QPushButton`, `QHBoxLayout`

---

### Задание 2 — Вычислитель выражений (1 балл)

**Файл:** `ex2.py`

В однострочное поле вводится корректное арифметическое выражение. По кнопке «Вычислить» результат вычисляется с помощью функции `eval()` и выводится во второе поле. Некорректные выражения обрабатываются выводом сообщения об ошибке.

**Пример:** `1 + 2 * 3` → `7`

**Используемые виджеты:** `QLineEdit`, `QPushButton`, `QHBoxLayout`

---

### Задание 3 — Управление видимостью виджетов (2 балла)

**Файл:** `ex3.py`

На форме размещены три текстовых виджета, рядом с каждым — чекбокс. Состояние чекбокса управляет видимостью соответствующего виджета. Реализован один универсальный обработчик, определяющий целевой виджет через `sender()` и словарь соответствий.

**Используемые виджеты:** `QCheckBox`, `QLabel`, `QVBoxLayout`, `QHBoxLayout`

---

### Задание 4 — Азбука Морзе (2 балла)

**Файл:** `ex4.py`

Кнопки с латинскими буквами создаются в цикле на основе словаря с кодами Морзе. При нажатии на кнопку в поле ввода добавляется код соответствующей буквы. Создание кнопок вручную не используется.

**Используемые виджеты:** `QPushButton`, `QLineEdit`, `QVBoxLayout`, `QGridLayout`

---

### Задание 5 — Заказ в ресторане (3 балла)

**Файл:** `ex5.py`

Форма представляет меню ресторана: для каждого блюда отображается название, цена, чекбокс выбора и счётчик порций. По умолчанию количество порций равно 1. По кнопке «Сформировать чек» выводится список выбранных блюд с указанием количества, стоимости по каждой позиции и итоговой суммы заказа.

**Используемые виджеты:** `QCheckBox`, `QSpinBox`, `QPushButton`, `QPlainTextEdit`, `QVBoxLayout`, `QHBoxLayout`

---

### Задание 6 — Калькулятор (3 балла)

**Файл:** `ex6.py`

Калькулятор поддерживает вещественные числа (положительные и отрицательные) и операции сложения, вычитания, умножения и деления. Вычисления выполняются последовательно. При делении на ноль и при некорректном выражении выводится сообщение об ошибке.

**Используемые виджеты:** `QLineEdit`, `QPushButton`, `QVBoxLayout`, `QGridLayout`

## Установка и запуск

### Требования

- Python 3.9 или выше
- PyQt6

### Установка зависимостей

```bash
pip install PyQt6
```

### Запуск

Каждый файл запускается отдельно:

```bash
python ex1.py
python ex2.py
python ex3.py
python ex4.py
python ex5.py
python ex6.py
```

---

## Примечания

- Во всех заданиях используется модульная структура с классом-наследником `QWidget`.
- Для компоновки элементов применяются `QVBoxLayout`, `QHBoxLayout` и `QGridLayout`.
- Обработчики событий подключаются через сигнал `clicked` и метод `sender()` для универсальной обработки.
