Технологии: Python, PyQt6

Описание
Лабораторная работа состоит из 6 заданий на разработку графических приложений с использованием PyQt6.

Задания
Задание 1 (ex1.py) — Перекидыватель слов
Форма с двумя полями ввода и кнопкой со стрелкой. При нажатии кнопки текст из первого поля переносится во второе, стрелка меняет направление. При повторном нажатии текст возвращается обратно.

Задание 2 (ex2.py) — Вычислитель выражений
Однострочное поле для ввода арифметического выражения. По кнопке «Вычислить» результат вычисляется через eval() и выводится во второе поле.

Задание 3 (ex3.py) — Управление видимостью виджетов
Три текстовых виджета с чекбоксами. Один универсальный обработчик скрывает и показывает виджеты в зависимости от состояния чекбокса.

Задание 4 (ex4.py) — Азбука Морзе
Кнопки с латинскими буквами, созданные в цикле. При нажатии в поле ввода добавляется код Морзе соответствующей буквы.

Задание 5 (ex5.py) — Заказ в ресторане
Меню блюд с ценами, чекбоксами и счётчиками порций. По кнопке «Сформировать чек» выводится список выбранных блюд с количеством, стоимостью и итоговой суммой.

Задание 6 (ex6.py) — Калькулятор
Калькулятор с поддержкой вещественных чисел и операций сложения, вычитания, умножения и деления. Обрабатывается деление на ноль и некорректные выражения.
